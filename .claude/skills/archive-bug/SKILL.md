# Bug 经验归档

## 触发条件

只在根因已确认、修复已完成且有可重复验证结果后触发。仍在猜测或尚未复现的问题继续留在诊断流程，不提前写成结论。

## 归档位置

- 活跃问题和安全分级遵循 `AGENTS.md` 指定的 `logs/issues.md`。
- 协议互操作证据优先更新 `docs/ngx-test-data/` 中对应文档。
- 可复用的架构结论更新 `docs/` 中现有主题文档。
- 不写入仓库之外的私人路径，不要求存在 commit hash。

## 记录内容

1. 症状、影响范围和稳定复现条件。
2. 根因所在入口、状态或资源边界。
3. 排除过的错误假设和关键证据。
4. 最小修复及为什么有效。
5. 回归测试、命令、日志或互操作结果。
6. 相邻风险、仍未覆盖项和再次排查入口。

## 规则

- 不复制真实凭据、密钥、完整用户流量和本机私有路径。
- 不把临时 workaround 写成架构设计。
- 不自动 commit、push 或 amend；提交行为必须由用户明确要求。
- 修复导致项目规则变化时，同步更新 `AGENTS.md` 或对应 skill。

## 相关 Skill

诊断见 `debug-cpp`，日志证据见 `parse-proxylog`，测试缺口见 `review-test`。
