# 智能体工作指南

## 开始前

- 阅读 [ARCHITECTURE.md](ARCHITECTURE.md) 了解系统地图和依赖规则。
- 规划非简单变更前，阅读 [docs/PLANS.md](docs/PLANS.md)。
- 修改某个领域前，阅读 `docs/` 下对应的产品、设计、可靠性、安全或前端文档。

## 工作规则

- 使用仓库已记录的安装、测试、检查、构建和部署命令。
- 在同一项变更中保持代码、测试、文档和生成产物一致。
- 遵守既定的依赖方向和架构边界。
- 将本文档的 `TODO` 视为缺失的仓库知识；依赖前先验证。
- 当仓库没有明确规则时，将产品选择、安全取舍、不可逆迁移和影响生产环境的操作升级给人类处理。
