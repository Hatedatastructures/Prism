# 流程图规范

## 默认格式

优先使用 ASCII 文本图，保证终端、Git diff 和不同 Markdown 渲染器中稳定。只有现有文档已经使用 Mermaid 且渲染链确认可用时，才继续使用 Mermaid。

```text
[Listener]
    |
    v
[Balancer] -> [Worker]
                  |
                  v
              [Session]
```

## 规则

- 数据或控制默认从上到下，次要分支从左到右。
- 节点使用简短名词或动词，不在框内写长段说明。
- 箭头旁只标必要条件，例如 `success`、`timeout`、`unknown`。
- 一个图只表达一个主题：调用链、状态机、所有权或错误传播。
- 图后用正文解释关键约束，不把所有细节塞进图中。
- 目录、类、函数和协议名使用仓库实际标识符。
- 更新代码路径或状态机时同步更新图。

## 状态机

必须显示初始状态、正常终止、错误终止和可重复关闭；循环边标明触发条件，避免无说明的回边。

## 所有权图

必须区分拥有、借用和 detached 边界，并标明 L1/L2/L3/L4 生命周期。不要用同一种箭头表示所有权和调用关系。

## 验证

在纯文本视图检查对齐、80-120 列可读性和节点名称。图中引用的路径和符号必须存在。
