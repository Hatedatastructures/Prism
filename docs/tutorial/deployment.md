# 部署

部署包至少包含 Prism 可执行文件、对应的 `PrismConfiguration.json`、运行时所需的 Web 资源，以及配置引用的证书和密钥文件。程序默认从可执行文件旁读取配置；部署时确认配置与二进制来自同一构建。

## 网络与凭据

- 监听地址必须存在于部署主机；仅在确实需要时绑定通配地址。
- 检查端口占用、防火墙规则和容器/服务管理器的端口映射。
- 通过 `PRISM_SECRET_` 环境变量提供 `SecretRef` 对应的值，避免写入镜像、仓库或命令行参数。
- 限制配置、证书、私钥和日志目录的文件权限；轮换凭据时同步更新安全存储和服务环境。

## Web 资源

CMake 构建会生成 Web catalog。默认 Web 资源目录位于 build 树的 `Web/`；若配置了 `Operations.WebDirectory`，程序按配置文件位置解析该路径。部署自定义目录时确认其中包含由构建生成的 catalog 和对应资源。

## 停机

通过服务管理器发送正常终止信号，让 Application 按关闭事务停止入口、排空活动任务并关闭服务。强制终止可能中断未完成请求；发生停机超时后先检查日志和资源 owner 状态，再决定是否重启。
