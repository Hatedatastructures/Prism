# Prism Web 质量约束

制定日期：2026-10-22。依据：用户要求前端与后端同等严谨，并以提供的 Visitly 界面作为视觉方向。

## 使用任务与视觉原则

首页优先支持观察运行：实时流量、连接数、资源占用。账户、连接和操作页面突出当前选中对象；配置遵循编辑、查看差异、选择保存方式、校验、应用的顺序。

- 界面使用中性画布、白色内容面、深色文字与主操作。状态颜色用于成功、警告和失败，不用于给普通数据增添装饰。
- 关键读数保持同等文字对比度；上下行和延迟系列同时采用文字图例与线型区分。
- 卡片分隔线属于装饰层；控件边界、选中标记、焦点和重要图形属于可辨识信息，不能共用过淡的线色。
- 修改颜色直接修改唯一 Palette；禁止在组件或样式末尾追加一套主题来覆盖旧主题。
- 实际截图必须分别检查文字可读性、对齐、信息密度、主次关系、控件状态及长文本。自动化检查不能替代视觉判断。

## 必须执行的检查

| 维度 | 门槛 | 可复现命令与范围 |
| --- | --- | --- |
| 类型 | 零类型错误 | `npm run check` |
| 行为 | 已有及新增断言全部通过，不跳过、不缩小输入凑通过 | `npm test` |
| 颜色归属 | 唯一浅色与深色 Palette，组件不含颜色字面量，不覆盖主题颜色变量 | `npm run check:palette`，使用 PostCSS AST |
| 文字对比度 | 实际使用的普通文字配对至少 4.5:1，直接比较未舍入数值 | Palette 约束与浏览器 axe 扫描共同检查 |
| 图形和控件 | 关键曲线、控件边界、焦点至少 3:1；不以颜色作为唯一提示 | Palette 约束、线型与焦点浏览器验证 |
| 可访问性 | WCAG 2 A/AA、2.1 AA、2.2 AA 所选规则零可检测违规；不使用 exclude/disable 掩盖问题 | `npm run test:a11y`；11 路由、浅深色、搜索框、手机导航、配置错误态 |
| 浏览器行为 | 桌面和手机场景全部通过，页面无 JS 错误、无横向整页溢出 | `npm run test:e2e -- --project=edge-1440 --project=edge-390` |
| 中间宽度 | 768、1280、1920、2265 像素不回归；详情宽度足够、行不互相遮挡 | `npm run test:e2e -- --project=edge-768 --project=edge-1280 --project=edge-1920 --project=edge-2265 --grep '所有工作区可渲染|概览按运行、代理资源、诊断任务分区|账户详情保持可读宽度'` |
| 交互 | 键盘可操作，焦点可见且能恢复；减少动态效果实际生效 | WorkspaceInteractions 与人工键盘检查 |
| 依赖 | 锁文件与声明一致，无高危及严重的已知依赖通告 | `npm ls --depth=0` 与 `npm audit --audit-level=high` |

axe 的 `incomplete` 表示工具不能自动裁定，必须保留报告并人工复核；零自动违规不能表述为完整 WCAG 认证。浏览器行为中的 API mock 证明前端处理契约，不替代真实服务验收。

## 数据和状态合同

- 未采集、无法计算、真实零值必须分开。容量为零时不显示 0% 使用率；缺测曲线保留断段。
- 速率、累计量、历史窗口、资源统计覆盖范围分别保留自身口径；不为了整齐而补造数据。
- 操作已受理、等待终态、成功、失败、结果未知分别呈现；非终态不用成功色，未知结果不能自动重发命令。
- 保留 Process、Incarnation、Generation 与资源身份核对。配置草稿来源、验证过的准确文本、发布前版本检查与完成后的读回保护不能减弱。
- 轮询不能抢走输入焦点、覆盖未提交草稿，或把保留的旧快照表示为刚刚成功采集。

## 性能和生产验收边界

本地 Vite 开发服务只能提供开发环境测量。对生产资源运行后的体积、缓存、首屏及交互性能另行记录；没有当前生产构建时，不填写虚构的 bundle 基线，也不将开发服务器测量作为生产通过证据。

生产体验目标采用 Web Vitals 的良好范围：LCP ≤ 2.5 秒、CLS ≤ 0.1、INP ≤ 200 毫秒。真实用户指标应按桌面和手机分别观察第 75 百分位；实验室点击耗时不冒充真实用户 INP。这些目标在取得可复核生产基线前列为待验收目标，不能声称已由本地测试执行。

`.github/workflows/web-quality.yml` 在独立 CI 工作区安装锁定依赖、检查源码与依赖、构建 Web 并对生产预览资源运行浏览器测试。只有实际 CI 成功记录才是该层证据；配置工作流本身不代表远端检查已经通过，也不代表分支保护已启用。此流程不验证 Prism C++ 静态资源服务与 catalog 链路。

## 防止质量回退

禁止新增 `@ts-ignore`、关闭规则、隐藏数据错误、未实现占位、跳过或删除测试以取得绿色结果。新增例外必须说明具体范围、原因、负责人和关闭条件；当前没有质量豁免。公开测试方法、完整失败结果及限制，不能只提供通过数量。
