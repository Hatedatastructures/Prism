# Web 前端执行约束

开始修改前阅读本目录的 [CONSTRAINTS.md](CONSTRAINTS.md)，不得通过降低阈值、删除断言、跳过测试或排除可访问性问题使检查通过。

本目录继承仓库根 AGENTS.md：保留现有工作树及用户进程，不使用 Python，不擅自构建、提交或推送。前端类型检查、测试与经授权的开发预览不代表生产构建或真实后端联调完成。

颜色只能定义在 `src/Styles/Palette.css`。组件使用语义变量；布局样式不得重新定义主题色。改变配色时同时检查浅色、深色、选中、焦点、缺测和错误状态。

修改完成后执行与影响范围相符的类型、行为、Palette 和浏览器检查，查看实际截图，并记录仍未验证的边界。测试数量、截图数量或单个工具的通过都不能单独作为质量结论。
