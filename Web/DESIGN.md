# Prism Web 设计合同

本文件定义 Prism 运维工作台自己的设计规则。外部参考只帮助校准表达方式，不复制品牌、文案或配色。

## 设计来源

以用户指定的 shadcn-admin 为布局与组件参考：使用中性画布、清晰的工作面、紧凑表格和克制的分隔。Prism 页面围绕实际代理数据设计，保留中性深灰深色主题和现有首页流量、延迟、RSS 趋势图。

## 页面任务

优先呈现当前状态、范围、异常和可以采取的操作；目录用于比较，选中对象用于核对身份、数据及关联资源。桌面以 1440px 为主要检查视口，同时验证 1280px 与 390px。

- 账户、用户组以紧凑目录和选中详情组织，清楚显示身份和范围；移动端账户以目录、详情切换。
- Worker、入口、Session、协议和操作中心以清单及详情对照，危险操作保留身份校验和确认。
- 资源分析分别呈现 RSS、PMR、BytePool、采样延迟和观测质量，不将统计范围不同的数值相加。
- 事件页保留窗口缺口、级别筛选和关联资源；配置页优先提供编辑空间，并保留校验、应用与读回。

## 视觉规则

- 所有颜色由 Palette.css 提供，浅色使用中性 Slate 和白色工作面，深色使用中性灰阶。状态色配合文字表达，不依靠颜色单独传递状态。
- 字体由 Palette 的 font-ui 变量统一定义。正文 16px，表格内容 15px；ID、地址和可比较的数值使用等宽字体或等宽数字。
- 优先用对齐、留白和分隔表达层次；避免重复的指标卡和无意义的嵌套。根据页面任务安排栏宽，允许数据表在窄屏局部滚动。
- 筛选、选中、焦点、加载、失败和禁用状态须清晰可辨；可分享的选择和筛选保留 URL 状态。

## 实时数据与 Session

- 轮询更新不能抢焦点、覆盖草稿、自动替换所选对象或无提示地重排用户正在阅读的列表。
- 实时读数和数据面板直接显示，避免整块入场动画造成刷新闪白。Trace 行直接显示“自 TCP 接入”的相对偏移；只有后端提供阶段耗时才显示阶段耗时。额度余额缺测或总额为零时，显示无法计算的原因，不绘制假占用比例。
- Session 活动清单、页面内最近观测留存和持久历史是不同范围。最近观测必须注明只保留本页实际读取到的记录；离开当前列表时先用完整 Process、Generation、Worker、Account、Session 身份重新核验。
- 没有可靠的终态接口时，不得把“已从活动快照消失”写成“连接已关闭”或编造关闭原因。两次轮询之间出现并结束的短连接只能标记为后端观测缺口。
- 关联事件、Trace、Streams、Tasks 和配额账本都要显示各自的身份、采样时间、加载范围、缺口或未提供状态；筛选只作用于已载入范围时必须明确说明。
- 不把未知、未采集、接口未开放、请求失败和真实零值合并；不按估算值补齐流量、配额、容量或协议实例归属。

## 交互与动效

- 优先组合现有 Radix Tabs、Select、Popover、Dialog、Tooltip 与项目语义组件；新组件按任务划分为比较视图、主从视图、证据时间线和工作流，不堆叠通用指标卡片。
- 仅对明确的按钮反馈、选中态、弹层和轻量状态变化使用短暂过渡；列和选中对象保持稳定，不对每条实时记录逐项播报或播放入场动画。
- 动画只改变明确列出的 `opacity` 或 `transform` 等属性，不使用 `transition: all`；所有动效服从 `prefers-reduced-motion`。
- 高信息密度区域优先保证行对齐、数值对齐、标签与口径邻近；不要以缩小全文字或移除有用字段换取留白。

## 验收

每个设计切片都要用真实页面内容检查桌面截图与关键交互状态；不只凭组件测试通过验收视觉。所有 11 个路由保持统一的颜色、字体、分隔线、焦点和状态语义，同时按页面任务保留自己的布局。颜色、类型、行为、无障碍和浏览器检查遵守 [CONSTRAINTS.md](CONSTRAINTS.md)；构建与真实后端验收遵守仓库 `AGENTS.md` 的授权边界。
